# 🚀 Asterios Launcher Login Manager

Утилита для удобного многопользовательского входа в клиент игры Lineage 2 сервера Asterios. 
Создавайте автономные профили и запускайте несколько аккаунтов без повторного ввода логина и пароля.

## ⚙️ Как это работает

### 🧩 Шаг 1: Создание автономного профиля в лаунчере

Перед использованием программы необходимо создать профиль для автономного входа прямо в официальном лаунчере:

1.  **Запустите** официальный лаунчер Asterios.
2.  **Введите** ваш логин и пароль в соответствующие поля.
3.  **Нажмите магическую комбинацию:**
    Удерживайте **`Ctrl`** + **`Стрелка вверх (↑)`** и, не отпуская их, **кликните левой кнопкой мыши** по кнопке **"ВХОД"**.
4.  **Готово!** В папке игры будет сохранен специальный файл профиля для автономного запуска.

### 📂 Шаг 2: Настройка и работа с программой

1.  **Укажите путь к лаунчеру:**
    *   В программе нажмите верхнюю кнопку **"Обзор..."**.
    *   Найдите и выберите исполняемый файл лаунчера (например, `A:\Asterios\Asterios.exe`).

2.  **Скопируйте и сохраните профиль:**
    *   Нажмите кнопку **"Скопировать текущий профиль"**.
    *   В открывшемся окне дайте профилю понятное имя (например, `ПеПе`).
    *   Профиль сохранится в папке `Profile` рядом с исполняемым файлом программы.

3.  **Добавьте другие аккаунты (опционально):**
    *   Повторите **Шаги 1 и 2** для каждого своего аккаунта, давая профилям уникальные имена.

4.  **Быстрый запуск аккаунтов:**
    *   В основном окне программы для каждого из 9 слотов нажмите кнопку **"Обзор..."** и выберите ранее сохраненный профиль.
    *   Для запуска игры просто нажмите соответствующую кнопку **"Start"** рядом с выбранным профилем.
    *   Есть возможность переименовывать кнопки запуска для удобства (клик правой кнопкой мыши по кнопке запуска).

## 🎯 Основные функции

*   **Управление профилями:** Создание и хранение отдельных профилей для разных аккаунтов.
*   **Мультизапуск:** Поддержка до 9 независимых слотов для быстрого запуска нескольких клиентов.
*   **Гибкая настройка:** Возможность переименовывать кнопки запуска для удобства (клик правой кнопкой мыши по кнопке).
*   **Портативность:** Все настройки хранятся локально в папке с программой.

## 💡 Советы

*   Называйте профили понятно (например, `БД`, `СЕ`, `Спойл`), чтобы не запутаться.
*   Используйте правый клик для переименования кнопок запуска прямо в интерфейсе.
*   Папку `Profile` можно скопировать и перенести вместе с программой, чтобы сохранить все настройки.

---

## ⚠️ Примечание

Данная программа является внешней оболочкой-помощником и не производит вмешательства в файлы игры или лаунчера. Она использует официальный функционал автономного входа, предоставляемый самим лаунчером Asterios.
